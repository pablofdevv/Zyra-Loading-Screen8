# 💧 Zyra Loading Screen 8 - Liquid Metal Edition

Welcome to **Zyra-Loading-Screen-8**, an organic fluid loading screen resource by **Zyra Store**. Built with fluid chrome liquid metal blob background animations and Swiss minimalist layout aesthetics.

## 🛠️ Key Features

- **Liquid Metal Blob Canvas:** Animated organic mercury fluid background with metallic gradient motion.
- **Swiss Minimalist Layout:** High-contrast minimalist typography with modern layout structure.
- **NUI Audio Controller:** Integrated music playlist with audio visualizer and volume slider.
- **Floating Glass Cards:** Translucent modular panels for community announcements, server rules, and social links.

---

## 📦 Installation Instructions

1. **Copy the Resource:**
   Place the `Zyra-Loading-Screen-8` folder in your `resources` directory:
   `resources/[zyra]/Zyra-Loading-Screen-8`

2. **Update `server.cfg`:**
   Add to `server.cfg`:
   ```cfg
   ensure Zyra-Loading-Screen-8
   ```

3. **Restart Server:**
   Save `server.cfg` and restart server or run:
   ```cmd
   refresh
   ensure Zyra-Loading-Screen-8
   ```

## ⚙️ Configuration Guide (`config.js`)

- **Server Branding:** Set server title, slogan, and header text.
- **Audio Playlist:** Add direct `.mp3` tracks, artist names, and default volume.
- **Social Media:** Set Discord link, Tebex webstore, and community platforms.
